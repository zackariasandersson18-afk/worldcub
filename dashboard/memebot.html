Experiment: vilka regler fungerar bäst?

samma tokens, olika säljregler · 5 000 kr varavgörs 25 okt
Bestämt i förväg (11 okt): en variant räknas som bättre än Kontroll bara om den den 25 oktober har minst 30 avslutade affärer och både högre netto och mindre största nedgång. Annars är den inte bevisat bättre. Test 66 startade tidigare och har annan kassa, så den jämförs inte direkt. Tryck på en rad för att se hela sidan för den varianten.

Varför tokens valdes bort

filter som skyddar kassan
Virtuell handel med riktiga priser från GeckoTerminal och DexScreener och säkerhetsdata från RugCheck. Regler bestämda innan start (test 66): köper 250 kr i nya Solana-tokens (10 min–6 h gamla) med minst 20 000 $ likviditet, köptryck och stigande pris, och bara om RugCheck inte hittar allvarliga risker, likviditeten är låst och de 10 största ägarna har högst 30 %. Säljer halva vid 2×, allt vid −40 % innan dess, resten vid 5× eller −50 % från toppen, allt efter 48 h. Varje köp och sälj prissätts med Jupiters riktiga offert för exakt den storleken (10 kr per dollar), minus 0,5 % för att priset hinner röra sig och 2 kr i nätverks- och prioritetsavgift. Finns ingen köpväg köps inget; finns ingen säljväg på tre minuter räknas affären som värdelös. Svarar Jupiter inte alls används 2 % som uppskattning och affären märks "uppskattad". Försvinner handeln räknas det som total förlust. Kollas varje minut, så ett fall mellan två minuter kan bli större än −40 %. Ingen finansiell rådgivning. Koppla från GitHub

Koppla GitHub för stäng-knappen
görs en gång – sedan stänger knappen direkt
  1. Öppna GitHub → ny fine-grained token.
  2. Namn: memebot stäng, utgång t.ex. 90 dagar.
  3. Repository access: Only select repositories → worldcub.
  4. Permissions → Repository: Issues → Read and write. Inget annat.
  5. Tryck Generate token, kopiera den och klistra in här.
Nyckeln sparas bara i den här webbläsaren på din egen github.io-adress och skickas bara till api.github.com. Ge den aldrig till någon, inte heller i chatten. Den kan bara skapa och läsa ärenden i worldcub – inte ändra koden. Du kan ta bort den med "Koppla från" längst ner.
